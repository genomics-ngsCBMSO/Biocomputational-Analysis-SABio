Step 0: Differentially Expressed Genes

Enrichment analysis starts from the results of differential expression analysis. Like other techiniques like bulk RNAseq, differential expression analysis in single-cell RNA sequencing aims to identify genes whose expression levels differ systematically between biological conditions, such as cell types or clusters, experimental conditions, cellular states, etc.

For this type of analysis we will generate the same plots as we do in bulkRNAseq DE

Step 1: Selection of Genes for Enrichment

Before performing an enrichment analysis, a set of genes must be defined according to the selected statistical criteria, e.g. adjusted p-value or magnitude of differential expression.

For ORA, the selected significant genes constitute the input gene list. This list can be separated into upregulated and downregulated genes in order to determine which biological functions are specifically associated with each direction of transcriptional change.

In contrast, GSEA does not require the selection of only statistically significant genes. Instead, the complete set of tested genes is ranked according to a differential expression statistic and used as input for the analysis.

This distinction is important because ORA and GSEA answer slightly different biological questions.

Step 2: Over Representation Analysis (ORA)

Over-Representation Analysis (ORA) tests whether genes from a predefined list occur more frequently than expected by chance within specific biological categories.

We use clusterProfiler, an R package, to perform this analysis on the input gene list consists of significantly differentially expressed genes obtained from the previous differential expression analysis.

ORA can be performed against several functional databases. The main databases included in this workflow are:

  • Gene Ontology (GO) Biological Process: identifies biological processes associated with the input genes.
  • KEGG: identifies metabolic, signaling and other biological pathways represented by the input genes.
  • Reactome: identifies genes associated with curated molecular reactions and biological pathways.

Statistical significance is assessed for each functional category and corrected for multiple testing. Pathways with significant adjusted p-values are considered enriched within the analyzed gene list.

Step 3: Gene Set Enrichment Analysis (GSEA)

Gene Set Enrichment Analysis (GSEA) provides a complementary approach to ORA. Instead of selecting only genes that pass a predefined significance threshold, GSEA evaluates the complete ranked list of genes obtained from differential expression analysis.

Genes are ranked according to a statistic that reflects the direction and strength of differential expression. Functional gene sets are then evaluated to determine whether their genes tend to accumulate toward the top or bottom of the ranked list.

A positive enrichment score indicates that genes belonging to the pathway tend to be located toward the top of the ranking, whereas a negative enrichment score indicates enrichment toward the bottom of the ranking. The magnitude and significance of the enrichment are summarized using the normalized enrichment score (NES) and its associated statistical significance. As with ORA, GSEA can be performed against Gene Ontology, KEGG and Reactome pathway collections.

GSEA is particularly useful when many genes show coordinated but relatively modest changes in expression that may not individually pass a strict differential expression threshold.
