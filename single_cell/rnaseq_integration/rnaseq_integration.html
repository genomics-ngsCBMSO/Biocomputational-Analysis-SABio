Step 1: Single Cell reference preparation

The annotated single-cell dataset generated during the previous single-cell analysis workflow is used as the reference dataset.

The reference contains the expression profiles of individual cells together with their assigned cell-type annotations. These annotations are essential because they define the cellular populations that will subsequently be identified in the bulk samples.

As a first step, the annotated single-cell dataset is summarized to generate representative transcriptional profiles for each cell type using the R package Seurat. Rather than comparing individual cells directly with bulk samples, cells belonging to the same annotated population are aggregated to obtain a representative cell-type-specific expression profile.

The resulting cell-type-by-gene matrix forms the basis for subsequent bulk–single-cell correlation and deconvolution analyses.

Step 2: Correlation Analysis

A first level of integration consists of comparing bulk expression profiles with the cell-type-specific profiles derived from the single-cell reference. The objective is to determine which cell-type-specific transcriptional profiles are most strongly represented in each bulk sample.

A high correlation indicates similarity between the bulk transcriptome and a cellular transcriptional program. However, correlation should not be interpreted as a direct estimate of cell-type abundance.

Correlation analysis can be performed in R using Pearson or Spearman correlation, with visualization performed using packages such as pheatmap or ComplexHeatmap.

Step 3: Bulk RNA-seq Deconvolution

Bulk RNA-seq measures the combined expression of all cells present in a sample. Deconvolution aims to estimate the relative contribution of different cell types to the observed bulk transcriptome. The annotated single-cell dataset is used as a reference to define cell-type-specific transcriptional signatures. These signatures are then used to estimate the relative abundance of the corresponding cell populations in each bulk sample.

Several reference-based deconvolution methods are commonly used for scRNA-seq-informed bulk RNA-seq analysis, including CIBERSORTx and MuSiC.

CIBERSORTx is a widely used framework based on support-vector regression and can construct cell-type-specific signatures from single-cell data. MuSiC incorporates information from multiple subjects and accounts for variability between individuals and within cell types.

The choice of method should therefore depend on the experimental design. The output is typically a matrix in which rows correspond to bulk samples and columns correspond to estimated cell types. These estimates can then be compared between experimental conditions to determine whether changes in bulk transcriptomes may be associated with changes in cellular composition.

Deconvolution results represent computational estimates rather than direct measurements of cell abundance. Their reliability depends on the quality and biological relevance of the single-cell reference, the similarity between the reference and bulk samples, and the degree of transcriptional overlap between cell types.

Step 4: Cell-Type Contribution to Bulk Expression

Once cell-type proportions have been estimated, the next objective is to determine how much each cellular population contributes to the transcriptional signal observed in bulk RNA-seq.

CIBERSORTx can be used again in this step. This analysis helps distinguish between two possible explanations for a change in bulk expression: an increase in the abundance of a cell type, or a change in the transcriptional state of that cell type.
